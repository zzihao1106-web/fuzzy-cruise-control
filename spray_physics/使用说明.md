# 喷雾物理约束识别工具 V2

这是可重复运行的本地桌面工具。选择图像文件夹，设置一次背景帧和标定，自动处理整个序列。首版适用于固定相机、固定喷嘴及向外发展的喷雾；亮喷雾和暗喷雾均可选择。

## 启动与试用

本机 Python 和依赖已可用。双击同目录的 `启动工具.bat`。

本机保留了私有示例配置时，可点击“载入本机60mm示例”重新运行。Git仓库不包含本机路径或原始实验图像；新下载的工具请先选择输入文件夹。

处理其他实验：

1. 选择一个图像序列文件夹，填写单独的结果保存位置。
2. 填写起喷前背景帧数和采样率。背景帧必须没有本次喷雾。
3. 点击“加载 / 自动估计”，检查喷嘴和视窗。如果不准确，点击“标喷嘴”后点一次喷嘴中心；点击“标定圆周”后点同一个圆周上相隔较远的三个点。
4. 填写标定圆的实际直径。本次圆直径60 mm；其他实验按实际情况填写。留空时只输出像素长度，不输出毫米长度。
5. 选择亮/暗喷雾或自动判断，点击运行。每个文件夹只设置一次，无需逐帧操作。
6. 打开结果文件夹，先看 `方法对照总览.jpg`、`末帧识别对照.jpg` 和 `识别过程慢放.gif`。

相机、视窗和分辨率相同的实验可以保存/加载配置复用标定；相机或图像裁切改变后需重新标定。新输入默认重新估计几何，避免误用旧坐标。

## 怎样理解结果

- 绿色：图像变化提供支持的区域或边界。
- 橙色：模型包络中缺少直接图像证据的区域或低证据边界。
- 紫色：不能当作当前测量的未知区域。无观测帧的虚线只表示预测。
- 黑色背景抑制图：显示可提取的亮/暗变化信号，没有凭模型补画缺失的纹理。

`envelope_masks` 是喷雾外包络，不能把它直接当作所有液滴的像素真值；`evidence_masks` 是有变化支持的区域；`inferred_masks` 是二者的差集。橙色区域需要重点检查。

当前样例标定约0.0871 mm/px，环境背压40 bar。喷射压力、密度或速度系数没有确认齐全时，压差速度公式不会强行启用；增长拟合和时序约束仍可使用。

V2将观测与预测分开。状态为`unknown_no_observation`时，`measurement_valid=False`，包络面积和前沿距离留空；不把未知误写成零面积。速度只在连续的可观测片段内计算，不跨越未知帧。

## 导出文件

| 文件/目录 | 内容 |
|---|---|
| `方法对照总览.jpg` | 各阶段原图、背景差分、分类和边界 |
| `识别过程慢放.gif` | 自动识别过程预览，播放速度不是采集速度 |
| `标定与视窗.png` | 选取的视窗、喷嘴与10mm比例尺 |
| `envelope_masks/` | 每帧外包络二值掩膜 |
| `evidence_masks/` | 每帧图像证据掩膜 |
| `inferred_masks/` | 每帧低证据推断区域 |
| `unknown_masks/` | 不能作为确定测量的未知范围 |
| `model_added_masks/` | 在局部弱信号和邻角支持下由模型增加的少量区域 |
| `background_removed/` | 每帧背景抑制图 |
| `overlays/` | 代表帧边界叠加图 |
| `frame_metrics.csv` | 投影面积、前沿分位数、证据比例 |
| `jet_metrics.csv` | 按同一喷束导出的前沿距离和经平滑的投影速度 |
| `contours.csv` | 轮廓角度、坐标、像素/毫米距离和证据标记 |
| `growth_models.csv` | 各喷束增长拟合参数、误差和借用模型标识 |
| `运行配置.json`、`run_summary.json` | 复现参数、输入映射摘要、排除的附件和运行统计 |

速度仅在空间标定、帧率和连续帧假设有效时解释。切勿将投影速度当成真实三维流速。

## 命令行与批处理

在工具目录运行以下命令（路径按实际情况修改）：

```powershell
python spray_recognition.py --input "D:\实验\序列A" --output "D:\结果\序列A" --diameter-mm 60 --fps 10000 --background-frames 5
```

新输入默认自动估计几何。若明确要复用配置中的同一标定，加 `--reuse-geometry`。也可用 `--config "设置.json"` 载入完整配置。

多个直接子文件夹分别包含一段序列时：

```powershell
python spray_recognition.py --input "D:\实验" --output "D:\批处理结果" --batch --diameter-mm 60 --fps 10000
```

每个子文件夹单独估计背景和几何，失败的序列写入 `batch_summary.json`。全部失败时程序返回错误。首版批处理假定各序列采用同一标定圆实际直径和帧率；不同工况可分别保存配置运行。

## 参数调整与当前限制

- 变化阈值较大：通常减少噪声，也可能丢失薄弱喷雾。
- 增长模型权重较大：更依赖前沿模型补足缺失区域，也更容易在模型不合适时产生过度推断。
- 背景帧含有喷雾、喷嘴中心偏移、标定选错圆，是应先排查的问题。
- 自动圆检测失败时会用候选几何供预览，应人工一次修正；单喷束的源点自动估计尤其需要检查。
- 当前实现使用极性归一后的背景变化和极坐标前沿代价，尚未实现技术方案中全部配准、纹理分类、阶段识别和置信度校准功能。
- 当前只有一组真实实验演示；合成测试用于检查程序与约束，尚无真实人工边界标注，不能宣称真实IoU或跨工况精度。

## V1/V2版本和对照检查

Git标签`spray-v1.0.0`保留初版，`spray-v2.0.0`对应本轮修正。新算法在独立`recognition_core.py`中实现；图像明确时允许否决增长模型。模型补全距离有限，窗框边缘的弱反光会被更保守地处理。

可重复运行真实序列检查：

```powershell
python benchmark.py --config config.json --baseline "旧版结果目录"
```

该命令输出`benchmark.json`和`V1_V2效果对照.jpg`。强变化保留率、末帧无信号反事实用于回归检查，均不是人工标注准确率。

此版本是用于检查效果的实验原型。原始文件不移动、不重命名；结果写入单独目录。
