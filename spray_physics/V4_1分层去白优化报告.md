# V4.1 分层去白优化报告

版本：4.1.0-alpha1。更新：2026-10-31。旧V4.0权重、结果和Git标签保留，新增版本不覆盖原始图像。

**当前状态：用户反馈处理不理想，未通过真实效果验收。** 下文“推荐”仅表示本轮候选之间的比较，不表示已达到可用的喷雾识别精度。该版本作为未达标的研究基线保存，不继续用合成指标代替真实验收。

已确认工况：柴油、环境背压40bar、喷油端名义压力140MPa、喷孔直径0.23mm、视窗直径60mm。喷油压力的基准仍未注明；这些是实验记录，本轮没有将其用于定量喷速硬约束。

## 1. 优化的问题与方法

旧V4输出接近`I-B-N`，保留的是背景差分中的变化量。亮背景透过衰减与喷雾前景的增亮可能抵消，使差分变小；这时继续增加扣除量会加重暗带。

本轮增加分层模型，网络分别估计有效混合系数alpha、前景F和背景亮度扰动，按下式重构观测：

`I ≈ (1-alpha) · B_hat + alpha · F`

去白图保存模型估计的`alpha · F`。前景层不必等于原图与背景的差，因此可尝试保留重合区的喷雾。该思路参考[BackgroundMattingV2的背景参考、alpha及前景接口](https://github.com/PeterL1n/BackgroundMattingV2/blob/master/doc/model_usage.md)；仍采用本项目的NAFNet结构改写基干，未套用现成人像权重。

这是简化成像假设，不是已验证的柴油散射精确模型。alpha是有效混合系数，不能直接解释为浓度、液滴体积分数或真实光学厚度。完全无对比处的估计仍依赖训练先验，不能当作新增观测。

## 2. 训练与版本选择

合成数据按上述混合关系生成，分别保存前景层、alpha和背景扰动。特意加入前景亮度接近亮背景的情况；这些样本的差分接近零，但真实合成前景仍存在。监督同时约束alpha、前景、背景扰动和原图重构，防止整幅抹黑或直接复制原图成为退化解。

恢复器训练1000步；第一组边界网络训练500步、增益2。发现部分显示饱和后，复用同一恢复器，重新训练500步边界网络，固定增益1，作为推荐候选。边界网络训练与推理的灰度增益和8位量化保持一致。

另外训练400步的物理投影候选，尝试将背景贡献限制在观测范围并保留纹理。其开发对照误差与过估倾向更大，没有设为默认；代码和权重仍保留作研究对照。

推荐恢复器408195参数；原阶段峰值显存约1013MiB。仅有合成监督，真实人工标注仍为0。第一阶段训练来源及各次冻结恢复器再训练的哈希分别保存，不把多组边界训练步数合并冒充一个模型的有效训练量。

## 3. 合成验证与限制

开发对照种子984203用于比较直接分层与物理投影。推荐模式确定后，再以新种子984204评估64张合成图像。该留出仅表示新的程序生成背景和喷束，不是独立真实实验。

本轮评分目标是已知合成前景层`alpha · F`；旧V4预测的是变化量，二者成像含义不同。对照说明旧变化量在本成像假设下难以保留相消区域，不能直接据此推断真实图像误删比例。

| 最终合成留出指标 | 旧V4变化量 | 推荐分层模式 |
|---|---:|---:|
| 弱对比区前景MAE | 0.18844 | 0.07911 |
| 同一弱对比定义的误差降幅 | — | 约58.0% |
| 前景整体MAE | 不混称同定义恢复误差 | 0.06755 |
| 已知背景前景残留MAE | 不以成像差异代替同类指标 | 0.00642 |
| 前景能量比，理想为1 | 不与变化量直接混比 | 1.1228 |
| 投影前的原图重构MAE | — | 0.00943 |

推荐模式仍有约12.3%的合成前景能量高估倾向。开发对照中，直接分层与物理投影的能量比分别约1.170和1.206，弱区MAE分别约0.0976和0.1085；这些不是最终留出种子的结果。不能只报告弱对比误差下降而忽略过度补全。

物理投影后的代数恒等重构不是独立精度证据。训练约束和以上重构误差使用投影前的网络分解，避免把强制合成相等冒充模型已经正确。

## 4. 真实序列检查

保持严格顺序：先完成全部70张去白PNG，再独立读取这些PNG识别边界。恢复器内部的连续alpha用于成像分解，来自恢复模型，不是事后拿边界二值掩膜把原图涂黑。

新版本另输出`opacity_frames/`和`restoration_unknown/`。原图变化低于起喷前噪声支持，或网络重构冲突较大的前景估计，记为未知。未知图只传播给边界的置信度显示，边界网络仍只接受去白PNG作为图像输入。

同增益1的空背景检查：

| 检查 | 旧V4 | 新分层模式 |
|---|---:|---:|
| 第4帧白区平均灰度，量化前 | 0.731 | 0.0281 |
| 第5帧白区平均灰度，量化前 | 0.722 | 0.0280 |
| 新版已保存8位PNG白区均值与99%分位 | — | 两帧均为0 |

8位量化为0不表示网络浮点输出绝对为零。旧版默认增益3、新版增益1；本表及`同增益效果对照.jpg`已统一增益1，避免将显示增益变化当作算法改善。

第6帧1138个强变化像素，在新版处理图中全部保持高于5灰度可见；这是明显信号保留检查，不是准确率。70张处理图与边界实际读取图的哈希全部一致，原图70张SHA256与原清单一致，去白和边界动画各70帧。

视觉上，晚期中央与左右重合区比旧差分结果更连续，但左侧仍留有暗缺口，窗框有伪前景，低证据区域及部分边界断裂仍明显。不能宣称已经恢复完整真实纹理，也不能据此给出真实边界IoU、面积或喷速结论。

## 5. 工具与复现

本机继续双击`启动工具.bat`并点“载入本机去白示例”，当前默认示例改为推荐分层模型；原V4启动设置已另存至旧结果目录。其他机器使用配套权重`models/restore_spray_v4_1_alpha1.pt`，仍选择“V4先去白再识别”。旧权重可继续加载。

```powershell
python restore_spray.py train --model optical --data deep_runs/数据 --output deep_runs/分层训练 --steps 1000 --boundary-steps 500
python restore_spray.py train --model optical --data deep_runs/数据 --output deep_runs/边界增益1 --resume-cleaner deep_runs/分层训练/cleaner_best.pt --steps 0 --boundary-steps 500 --foreground-gain 1
python restore_spray.py process --config 设置.json --checkpoint deep_runs/边界增益1/pipeline_best.pt --output deep_runs/分层结果
python restore_spray.py evaluate --data deep_runs/数据 --checkpoint deep_runs/边界增益1/pipeline_best.pt --baseline 旧V4权重.pt --seed 984204 --output deep_runs/合成留出.json
```

`--physical-projection`为非默认候选，需重新训练与其输入定义匹配的边界模型，不建议仅修改权重元数据来切换。恢复与边界始终先后执行，旧V4的复现训练应显式使用`--model residual`。

本轮检查包括新旧权重兼容、合成成像关系、零对比不等于零前景、物理投影约束、小规模实际训练、冻结恢复器再训练、落盘PNG及批处理。仍需真实代表帧标注及其他实验序列验证。40bar继续仅作为工况记录，尚未接入喷速及时间增长物理模型。

## 6. 根据真实效果反馈调整下一阶段

当前单帧恢复器主要用合成配对训练，没有真实无白斑喷雾目标。空背景只能提供灯斑特征，不能直接提供被灯斑覆盖的喷雾真值，因此容易擦弱喷雾或依靠形状先验补出前景。继续训练相同合成数据不足以证明可以解决该问题。

下一步先接收完整高速视频或其他真实喷射序列，核查起喷前背景、采样率、曝光和视角；按完整实验划分开发与留出序列。用户已表示另有原始数据，路径尚待提供。

模型方向改为背景参考加短时序恢复，优先比较中心帧与前后各2帧的特征，避免将移动喷雾直接平均成模糊图。可参考[RVRT官方视频恢复结构](https://github.com/JingyunLiang/RVRT)的多帧特征融合与对齐思路，但原自然视频权重不能视为喷雾去白模型，当前尚未接入或训练。

训练需要少量真实复核：确定喷雾、确定灯斑背景和未知区分开；清晰真实喷雾纹理可用于构造受控污染配对，不能把当前去白输出或不可见边界直接当作真值。损失同时限制白斑残留、喷雾损失、时序冲突与适用的成像约束，未知区域不强行监督成背景。

先单独验收去白图，检查固定灯斑是否去除、可见喷雾是否保留、是否产生伪前景；去白效果通过后，再评价只读取去白图的边界模块。新增数据路径到达前不将扩大模型或延长同样训练当作已经改善真实效果。
