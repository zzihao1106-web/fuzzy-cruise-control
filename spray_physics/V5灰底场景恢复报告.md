# V5灰底场景恢复试验

日期：2026-10-31。版本：5.0.0-alpha1，研究试用版。

## 问题和输出定义

用户需要将打光白斑校正为偏灰基座颜色，保留喷孔和完整喷雾场景，然后捕捉喷雾边界。历史V4黑底前景图不满足这一输出定义。本版在已确认的B方案灰底参考上继续开发，逐帧输出完整灰底场景。

目前数据为一段70张1280×800图像，前5张按无喷雾背景处理，前3张估计背景，第4、5张保留为空背景复核。液体柴油，背压40 bar，喷油端名义压力140 MPa，喷孔直径0.23 mm，视窗直径60 mm。喷射压力基准、密度和流量系数尚不齐全，本版不使用压差喷速上界，不把10000 fps及连续帧假设转换成已验证喷速。

## 可复现方法

1. 从起喷前背景建立原始照明参考B_lit和保留细纹理的灰底参考B_gray。灰底估计及几何保护沿用gray_background.py；不同照明方向可能需要重新定义灰色采样区域。
2. 仅用视窗外静态区域估计曝光增益/偏置，归一化当前帧。前、当前、后帧与两张背景参考以及差分共同构成9通道输入。使用后帧意味着这是离线算法，不能当作因果实时推理。
3. 三帧网络复用本项目NAF结构骨干，输出喷雾不透明度alpha、前景亮度和有限背景漂移。网络约40.9万参数。透明度和漂移在空背景参考响应上校零，以减少固定基座纹理的伪响应。
4. 采用简化成像模型I=T·B_lit+S，恢复目标J=I−T·(B_lit−B_gray)。T由网络及0≤S≤1−T的亮度范围约束共同估计，加入背景噪声容差。输出从测得当前图扣除背景贡献，保留当前图的细节，不生成喷雾纹理。该成像模型是近似，未验证对本实验所有散射条件成立。
5. 喷孔核心像素保持原样，边界平滑衔接。全部70张灰底PNG落盘后，才由独立模块读取这些PNG提取边界。
6. 边界阶段用校正图与其前3张背景的差异、自适应噪声阈值、强弱阈值连通和喷孔邻近连通约束识别。仅进行3像素局部闭合，不凭物理模型补齐整个喷束，不对后期消散施加单调增长条件。该阶段不再读取原始实验图，也不直接将网络透明度阈值当边界。

同亮度重合、范围约束冲突、过曝等恢复不确定性保存为独立图。边界在灰底校正图上显示，绿色为处理图支持的轮廓，紫色为低证据轮廓。两者均未通过真实标签验证，不作为定量实验测量。

## 训练与独立验证

训练尺寸256×256，batch=4，1000步，seed=20261031，AdamW初始学习率0.0015并余弦衰减。约222秒完成训练及合成验证；本机CUDA环境。最佳内部验证权重为第1000步。

训练使用真实空背景加程序背景，通过已知alpha、前景层及背景漂移合成三帧序列和灰底目标。相邻帧加入有限增长、消散、位移和噪声。没有将真实70帧随机分成训练测试，也没有将构造灰底直接当成真实含喷雾标签。独立测试使用分离随机种子和程序背景，48个合成样本；这是合成分布内的留出测试，不代表跨实验泛化。

| 独立合成测试指标 | 归一化灰度误差 | 换算0—255灰度 |
|---|---:|---:|
| 喷雾区域MAE | 0.02181 | 5.56 |
| 背景区域MAE | 0.00498 | 1.27 |

以上检验的是未经真实场景校零与物理投影后处理的网络输出；它不是完整推理流程的实测准确率。真实标签为0，不报告真实IoU、真实边界F1或真实喷雾保留率。

测试覆盖：相同喷雾在不同照明背景下恢复为同一灰底结果、不透明喷雾保留、边界阶段不依赖原图、准备—训练—保存—边界全流程。V5新增4项测试及旧版24项回归测试均通过。

GUI已校验V5模式、私有示例载入和实际命令参数路由，启动子进程在该项GUI检查中采用模拟；真实70帧处理由命令行完整执行，未把模拟启动记为另一次GUI全序列实跑。

## 使用

桌面启动tool_gui.py，选择“V5灰底场景试验”，载入匹配的gray_spray_v5_alpha1.pt权重，选择图像序列并检查一次几何标定。已配置本机“载入灰底场景示例”按钮。切换算法时必须选择对应权重，旧V4权重不能用于V5。仓库不保存实验原图、私有配置或权重；本机结果包单独保存权重。

命令行在工具目录运行：

```powershell
python gray_scene.py prepare --config config.local.json --output results/v5_data --size 256
python gray_scene.py train --data results/v5_data --output results/v5_train --steps 1000 --device auto
python gray_scene.py process --config config.local.json --checkpoint results/v5_train/gray_best.pt --output results/v5_result --size 256 --device auto
```

其他同类序列只需设置一次背景帧数及标定，可复用权重运行process，不需逐帧手工处理。相机或图像裁切改变时需重新标定；不同照明布局的泛化尚未验证。批量处理直接子文件夹可加--batch --input输入根目录。必须使用独立输出目录，不覆盖原始图像。

输出包括gray_frames/灰底逐帧图、opacity/估计不透明度、restoration_unknown/不确定区域、boundary/边界图及掩膜、灰底场景动画.gif、灰底恢复与边界总览.jpg、哈希映射、运行配置和摘要。摘要中的quantitative_measurement_valid固定为false，直到完成真实标注验证。

## 真实70帧运行与自评

本轮先以512尺寸推理，再以训练时的256尺寸复核；二者都完整输出70张灰底图及70张边界图。512结果在左右重合区有较硬的块状接缝；256结果过渡较平滑，因此桌面默认采用256，保留512结果作对照。这是目视外观选择，不是由真实标签精度选出的最优尺寸。最终逐帧图仍保存为1280×800，256仅是网络裁剪处理尺寸。

256方案恢复及边界流程约49秒，不包含训练与首次模块加载。前5帧的底座灰度标准差分别为2.69、2.70、2.69、2.94、2.90；原背景约34.64。独立保留的第4、5空背景帧未检出连通喷雾掩膜，前3张亦为0；输出均为灰底场景而非黑底图。所有帧运行断言喷孔保护区像素不变。

目视结果：左右强光带明显减弱，喷雾主体可见；但重合区仍有灰色扇形/块状过渡和局部暗区，薄雾与喷束间隙的恢复不可靠。部分轮廓有外扩，尤其不能将紫色边界当成正确测量。第20帧边界掩膜276344 px，其中79510 px为低证据；第50帧掩膜340353 px，其中46960 px为低证据。这些是算法输出规模，不能解释成喷雾真实面积或真实误差率。

本轮达成的是可复用的“灰底参考—三帧深度恢复—全序列落盘—处理图边界—报告”试用流程；尚未达成重合区域准确恢复或边界测量验收，不能宣传为问题已解决。

## 尚需验证的限制

这是将空背景样图接到完整序列的首版，不意味着同亮度重合区域已准确恢复。alpha与前景亮度可能互相补偿；曝光归一化和基座照明近似也可能引入偏差。高频划痕会受灰底参考影响，不能将输出解释为真实未照明表面。边界依赖恢复后的对比，恢复过弱或过强会造成遗漏或伪边缘。

下一阶段需要用户提供其他原始序列路径，优先包括更长无喷雾背景、不同喷射时刻以及同视角其他实验。选少量真实帧标注“确定喷雾/确定背景/未知”并按整段实验留出，检查白斑残余、薄雾漏检及边界误差后，再决定针对性微调。当前不为使轮廓完整而强行涂满未知区域。
