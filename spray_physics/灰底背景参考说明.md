# 灰底背景参考试验 v0.1

2026-10-31。本轮将无喷雾前几帧中的左右打光白斑替换为周围偏灰底座的色调，保留喷孔核心及圆窗位置，输出完整灰底场景。该阶段是可复现的像素算法，没有用生成式图像模型重画实验图，也尚未训练后续逐帧深度恢复网络。

## 三种方法

| 方案 | 处理方法 | 实际观察 |
|---|---|---|
| A 局部去白 | 稳健二次曲面估计灰底，识别大面积照明超额，羽化增益校正 | 白斑被压低，但仍有扇形明暗痕迹 |
| B 全基座均匀化 | 从非水平照明方向估计统一灰度；统一低频底色并保留限幅高频细纹理 | 灰底基本均匀，适合作为后续外观参考 |
| C 均匀灰底模板 | 使用同一底色，不添加原底座细纹理 | 最均匀；仅是构造的参考模板 |

B、C保留每张原图中喷孔核心半径约22.25 px内的像素，并在核心外平滑衔接。用圆周径向剖面统一环边照明，不改变图像坐标或圆窗几何；环边亮度会变化。基座的划痕、阴影等也会被削弱，不能将结果宣称为真实表面纹理恢复。

本段使用前5帧的中位数估计背景，随后将同一参考映射用于这5张无喷雾图，避免逐帧独立拟合造成底色跳变。复用到其他实验前必须确认所选背景帧没有喷雾，并重新检查几何标定；当前非水平采样区域针对本组左右打光布局，不保证适合任意照明方向。

## 验证

底色约69.63/255。在圆窗归一化半径小于0.90、排除距喷孔小于0.15倍短半轴的区域，原背景灰度标准差34.63，B为1.76，C为0。标准差只衡量均匀性，不能作为喷雾保留率、去白准确率或恢复真实度。运行时逐张断言保护区像素不变；已输出5张B和5张C背景并检查参考对照图。

## 运行

在工具目录运行，配置格式沿用config.example.json，填入本地输入路径、source_xy、chamber_xy、chamber_axes_px及background_frames：

```powershell
python gray_background.py --config config.local.json --output results/gray_reference --uniform-variants
```

输出原背景、A/B/C方案图、四格对照、参考参数、均匀性统计及每张背景图。输入图不会被覆盖；必须使用独立输出目录。此入口仅供空背景处理，不应传入含喷雾帧冒充校正结果。暂未接入GUI。

## 接下来的恢复目标

若原图可近似写为 I = T·B_lit + S，则灰底场景应恢复为 J = T·B_gray + S，其中T为透射率、S为喷雾成像贡献。直接将灰底覆盖到含喷雾白斑区域，会同时抹去真实喷雾，不能沿用本轮背景替换操作。

后续深度模型需要利用原始背景、灰底参考及相邻帧，估计照明贡献和喷雾成分，再逐帧输出灰底场景，最后从这些处理图识别边界。B/C不是配准的真实无光斑喷雾标签，不能直接作为有喷雾帧的监督真值；应结合额外原始序列、合成分层样本和独立真实标注验证。尚未恢复的重合、过曝区域需保留不确定性。
