# 喷雾深度背景分离：算法与工具选型 V3

调研日期：2026-10-30。状态：完成公开资料选型，尚未安装深度学习环境、下载模型权重或训练。现有可运行算法仍为 V2.0.1，本文件不代表 V3 效果已实现。

## 1. 结论与项目目标

推荐先实现轻量的背景条件 U-Net，输入当前帧、原始空背景及双极性差分，联合输出喷雾概率、边界和不确定区域；建立可靠基线后，再增加共享参数的迭代细化与短时序状态。借鉴 BackgroundMattingV2 的空背景参考及粗到细结构，同时使用公开喷雾分割模型作领域对照。

这是一条针对本项目拟定的组合路线，不是已有开源模型已经解决当前柴油喷雾问题。用户提出的“参考空背景、逐轮削减白斑”适合作为研究方向，但必须同时约束喷雾保留，不能只追求原图与背景的总残差趋零。

本次工况沿用已确认的柴油、40 bar 环境背压、60 mm 视窗。当前只有一段70帧序列，前5帧作为候选空背景需要复核。原始背景必须保留，任何去白背景仅作为辅助图；过曝或完全无对比处仍可能无法唯一判断，应输出未知区域。

## 4. 拟实现的数据流

1. **背景建立**：确认起喷前帧，配准后取稳健背景 B 和噪声尺度图；保存原始B。记录白斑位置与饱和区域，不把所有亮像素当作应删除的背景。
2. **成像校正**：只用可信静态背景估计有限幅度的曝光增益、偏置和缓慢光照变化，得到当前对应背景 B_t。后期缺乏可信背景时冻结或降级，避免把喷雾吸收到背景。
3. **基线网络**：输入 `[I_t, B_t, D_+, D_-]`，其中 `D_+=max(I_t-B_t,0)`，`D_-=max(B_t-I_t,0)`。既保留散射增亮也保留消光变暗；不能简单取绝对差后全部认作喷雾。
4. **联合输出**：喷雾概率、边界、未知区域，必要时增加辅助分离图。先保证边界任务可训练，再决定是否增加alpha分支，不以“图像更黑”作为正确分离证据。
5. **迭代细化**：基线通过后，初试3次共享参数更新。每次访问原图与原始背景参考，更新当前分离和边界估计；3次只是可做消融的初值，不保证更多轮一定更好。
6. **时序与物理**：最后加入短时序状态及软约束。清晰观测优先；未观测到的边界单独标未知，不能由增长先验写成确定测量。

辅助观测关系可写成 `I_t ≈ T_t · B_t + S_t + η_t`，分别描述背景透过、散射及噪声。这是待校验的简化关系；T与S仅凭一张灰度图不可唯一分离。若使用alpha混合模型，应明确其假设，不把alpha和T机械视作同一个实测物理量。

## 5. 训练约束与停止条件

联合目标包含：可信背景区域的残留、已标喷雾区域的保留、边界误差、有效区域的图像重建、时序一致性及适用阶段的物理软约束。未知带不参加确定前景/背景的硬监督；各项权重通过验证集与消融选择。

禁止只最小化整幅 `|I-B|` 或强制每轮喷雾信号递减。把整幅喷雾一起抹掉也能降低这种残差，是必须排除的退化解。迭代收敛应同时检查可信背景残差、喷雾保留和边界变化，并设最大轮数。背景残差阈值由留出的空背景噪声估计，不能拍脑袋设一个适用于所有实验的数值。

物理约束先用标定视窗、喷嘴关联和软时序连续性。向外发展、增长关系或单调性只在适用的喷射阶段使用，撞壁、喷射结束及扩散阶段应切换。40 bar是环境压力，不能单独确定喷速；物性、喷孔及压力基准不足时，不启用定量压差速度硬约束。

## 6. 小数据策略与验证

- 先标第6、10、12、14、16、18、19、20、54、70帧，覆盖短喷束、白斑重合、局部突跳和晚期形态；这些是现有诊断给出的复核候选，不是自动真值。
- 标注确定喷雾、确定背景和未知边界带；同时标注需要重点评估的白斑重合区域。不要强行给完全不可见部分一个精确轮廓。边界带宽由图像复核确定，不固定假定为物理界面厚度。
- 用真实空背景合成不同强度、透明度、模糊、增亮/变暗和时序增长的喷雾样本，产生可控监督；合成样本只能用于预训练与反事实测试，不能代替真实效果评价。
- V2高置信区域可生成待复核草稿，不能把V2已知缺口和误检直接当监督真值，也不应把未审查输出当独立测试标签。
- 只有这一段70帧时，先做内部原型验证，固定留出代表帧并防止相邻帧泄漏；不能宣称跨实验泛化。正式训练/验证/测试按完整实验序列划分，背景参考使用方式也需随序列固定记录。

统一比较：V2、背景条件U-Net、加入迭代、加入时序/物理，以及适配成功后的公开喷雾模型。逐项加入模块，不一次全部堆叠后无法判断收益。

核心指标包括：白斑区背景误检率、人工确定喷雾区域召回、确定区域IoU、容差明确的Boundary F1、边界误差及未知覆盖率。未知带不直接计为确定错误，同时报告可评估覆盖率，防止模型靠把所有区域标未知获得好分数。毫米误差在60mm标定有效的前提下换算。

保留起喷短喷束、空背景误检、光照漂移和无观测反事实测试。无观测时不强迫真实喷雾消失，而是将测量降级为未知。训练损失下降、背景变黑、强信号保留100%均不等同真实边界准确率。
