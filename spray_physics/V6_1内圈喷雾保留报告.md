# V6.1内圈喷雾保留修复

日期：2026-11-02。版本：6.1.0-alpha1，保守试用模式，未通过真实配对验收。

## 用户问题与定位

用户在慢放视频中指出，后段喷孔周围一圈弥散喷雾被背景优化削弱。对照原始第24、50、70帧与V6去白图，近喷孔的连续雾状亮度确有明显降低。22像素喷孔核心始终保留，但核心外较大的区域仍被参与背景扣除，二者不是同一保护范围。

发现具体训练缺口：V6准备真实纹理样本时，排除了半径0.09倍裁剪图尺寸的区域，换算回原图约65像素，再经过腐蚀扩大到约65—75像素；真实喷孔核心半径只约22.25像素。半径35—65像素环带的训练有效像素比例为0。因此该内圈缺少恢复监督，后期低对比雾容易与背景混淆。该缺口是明确风险因素，不能据此断言所有压暗都由它单独造成。

## 实际采用的修复

最终试用结果冻结原V6网络权重，只增加有图像证据支持的扣除限制。不是将整个圆形原图区域粘回，也没有用生成式工具补画喷雾。

1. 以当前及前后帧相对原背景的变化建立支持，减去背景噪声水平。仅保留与近喷孔变化相连的区域，避免孤立噪点触发。
2. 对小范围相消缺口做局部闭合与平滑，避免保护强度忽高忽低形成新的斑块。此传播是保守先验，不是直接观测，因此保护介入处仍标不确定。
3. 在非强白斑区域，给背景透射系数T加上保守上限，使有支持的内圈喷雾不再被同等强度扣除。空间权重连续衰减，没有固定半径的硬粘贴边缘。
4. 原背景比灰底高出至少80/255的强光核心不触发保护；中间亮度带平滑过渡。喷孔核心继续逐像素保持原图。
5. 仍使用J=I−T(B−G)，只减少符合条件的背景扣除，不主动绘制新纹理；变化以preservation_adjustment/逐帧记录。介入区并入restoration_unknown/，不因画面变亮就标为可靠测量。

默认source_preservation_strength=0.95。桌面界面提供0—1强度设置，0表示无保护，1最保守。也可用--disable-preservation做消融。强度是试用控制参数，不是实验测得的喷雾不透明度。

## 重训候选与未采用原因

另行修复了训练样本排除范围，改为只排除实际喷孔核心与小量边缘余量，新增内圈权重和过暗惩罚。35—65像素环带训练有效比例从0提高到约61.6%；该比例只是监督覆盖，不是识别准确率。

新模型完成1200步训练，按验证指标选第800步。64个同一留出代理样本上：

| 指标，0—255灰度 | V6原模型 | 新训练候选 |
|---|---:|---:|
| 内圈前景MAE | 3.79 | 3.81 |
| 内圈前景过暗误差 | 0.58 | 0.48 |
| 强光重合前景MAE | 7.51 | 7.93 |
| 背景MAE | 2.75 | 2.10 |

候选减少了过暗误差，但内圈总体MAE没有改善，真实强光区又出现局部暗带，不能仅凭单项指标升级。所以最终试用权重继承冻结的V6模型，并明确记录model_weights_retrained=false、parent_version和parent_sha256。新训练候选与失败对照单独保留，代码中的训练缺口修复也保留供后续研究使用。以上代理参考仍不是真实无白斑喷雾真值。

## 70帧检查与效果解释

最终保守修复完整处理70帧，先保存灰底图，再由独立模块读取它们捕捉边界。13项相关测试包括保留策略、空背景、强白斑、远处孤立变化、强度0回退、喷孔像素及保存后边界合同等检查；最终数量以验证摘要为准。

逐帧直接比较V6旧版与最终试用版：

- 前5张无喷雾图与V6逐像素一致；喷雾连通误检仍为0。
- 70帧喷孔核心原像素均保留。
- 全部70帧没有像素比V6进一步变暗。
- 按原背景减灰底至少80/255定义的强光核心，与V6最大相差1灰度；不能把这一量化定义扩展成所有肉眼认为的白斑区域都完全不变。
- 第70帧半径35—150像素环带，相对V6平均增加约9.88灰度，说明该处扣除确实减少；这是亮度变化，不是喷雾恢复率。

目视内圈连续雾状变化比V6保留更多，仍有局部阴影和背景纹理。限制扣除也可能留下部分背景成分，因此本模式优先避免误删，不能宣称恢复了真实散射强度。没有真实无光斑配对及人工标签，不报告实际保留率、实际IoU或测量有效面积。

本轮没有启用物理前沿硬裁切；旧物理预测报告基于原V6图像，不能把原有误差数字直接归给V6.1。

## 使用与版本回退

桌面“载入灰底场景示例”已指向内圈保留模式权重，仍可以选择原gray_spray_v6_alpha1.pt作对照。V6私有配置已备份；原始图像、V6结果和旧权重保持不变。

```powershell
python gray_scene.py process --config config.local.json --checkpoint models/gray_spray_v6_1_alpha1.pt --output results/v6_1 --size 256
```

新输出增加preservation_adjustment/及配置中的source_preservation_strength。报告、验证摘要、内圈放大新旧对照和短视频单独保存。视频三列使用同一显示亮度，没有为新版额外拉伸对比度。
