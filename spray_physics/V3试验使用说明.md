# V3 背景参考深度学习试验版

软件标识：3.0.0-alpha1。V2.0.1保持原入口与结果，V3需要单独的已训练权重。当前实现为自编轻量背景条件U-Net和共享细化模块，没有复制人像模型代码或将其权重冒充喷雾模型。

## 本机试用

双击`启动工具.bat`，选择“V3深度学习试验”，选择本轮训练输出的`best.pt`，再设置输入与一个新的输出文件夹。标定方式与V2相同。新序列需要起喷前空背景；背景帧不能包含本次喷雾。

本机如果在工具上两级目录存在`.venv-spray-v3/Scripts/python.exe`，界面自动使用该独立环境；其他机器使用启动界面的Python环境，需要先安装深度学习依赖。原始数据、权重、依赖环境和私有路径配置不进入Git。

## 其他电脑安装

建议创建独立环境，不升级已有V2的系统依赖。以下命令在工具目录执行，Python应满足所选PyTorch版本要求：

```powershell
python -m venv --system-site-packages .venv-v3
.venv-v3/Scripts/python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
.venv-v3/Scripts/python.exe -m pip install -r requirements-deep.txt
.venv-v3/Scripts/python.exe tool_gui.py
```

CUDA版本需结合显卡和驱动按[PyTorch官方说明](https://pytorch.org/get-started/locally/)选择。CPU环境可从官方CPU索引安装相应版本，但训练较慢。当前实现只使用PyTorch，不要求torchvision、TensorFlow或大型分割框架。

## 准备、训练与评估

以下`python`表示已经装好依赖的独立环境解释器；配置可由桌面工具保存。每轮试验使用新的输出目录。

```powershell
python deep_spray.py prepare --config 设置.json --output deep_runs/数据 --size 320
python deep_spray.py train --data deep_runs/数据 --output deep_runs/训练A --steps 1000 --batch 4 --device cuda
python deep_spray.py evaluate --data deep_runs/数据 --checkpoint deep_runs/训练A/best.pt --output deep_runs/合成测试.json
python deep_spray.py predict --config 设置.json --checkpoint deep_runs/训练A/best.pt --output deep_runs/推理A --size 512
```

`prepare`按自然顺序选主分辨率图像，保存每帧SHA256及原始背景。默认5个空背景时，只用第1—3帧建立参考和合成训练池，第4、5帧留作内部空背景检查。不是独立实验测试。合成训练随机加入程序生成背景；验证与测试使用不同随机种子，训练选最佳模型的验证集与最终合成测试种子分开。

`train --iterations 0`可训练不带细化的基线，默认`--iterations 2`进行两次共享细化。应分别从头训练、固定数据和预算后才能比较模块收益；同一模型去掉细化只属于运行诊断。`--resume`用于相同结构的权重热启动，不恢复优化器及随机状态，不能称为精确断点续训。

训练输出`best.pt`、`last.pt`、`training_log.json`、`training_summary.json`。权重文件记录结构、训练类型、随机种子、步数、训练标注文件清单和合成验证指标；运行报告记录数据清单哈希。仅从本人信任的来源载入权重。

## 真实标注与后续校正

```powershell
python deep_annotate.py --data deep_runs/数据 --output annotation_workspace/labels
```

左侧画确定区域，右侧看原始背景；按1选择喷雾、2选择背景、3选择未知/擦除，左右切换代表帧，S保存。切帧或关闭时保存已修改标注。未涂区域始终为未知，不会被默认当背景。导出的单通道PNG与原图同尺寸，值0=背景、1=喷雾、255=未知。

复核后可显式加入真实标注训练：

```powershell
python deep_spray.py train --data deep_runs/数据 --output deep_runs/真实校正A --resume deep_runs/训练A/best.pt --labels annotation_workspace/labels --steps 300
python deep_spray.py evaluate-labels --data deep_runs/数据 --labels annotation_workspace/留出标签 --checkpoint deep_runs/真实校正A/best.pt --output deep_runs/真实标签评估.json
```

真实标注不自动取自V2。评估会标明文件是否参加过真实监督训练，报告确定标注覆盖率；稀疏标注不足以代表完整边界。只有一组序列时，不报告跨实验泛化。正式研究需以完整实验序列划分训练、验证和测试。

## 输出解释

| 输出 | 含义 |
|---|---|
| `V3整段效果对照.jpg` | 第6、20及末帧，原图、双极性变化、模型概率、边界与未知提示；可选V2同图对照 |
| `probability/` | 原图坐标下喷雾概率的8位预览，数值未做概率校准 |
| `edge_probability/` | 边缘辅助头的8位预览 |
| `model_masks/` | 阈值、视窗与喷嘴连通筛选后的模型区域，不等同V2外包络 |
| `unknown_masks/` | 概率中间带及不可见性头的未校准提示；不代表所有错误均能被检出 |
| `signal_on_black/` | 模型区域内绝对观测变化的增强显示，不是反演恢复的真实喷雾图 |
| `iterations/` | 代表帧各轮概率，便于核查细化是否误删，不能假定逐轮必然更好 |
| `frame_metrics.csv` | 原始模型面积、筛选面积、未知、观测支持和细化变化等诊断量 |
| `deep_run_summary.json` | 权重哈希、训练类型、空背景误检、精确背景反事实及当前未实现功能 |

模型区域与未知提示可能重叠，表示“模型倾向于喷雾但证据不足”。无观测时，确定掩膜为空，模型预测转为未知；原始概率照常导出，以便发现网络是否凭空画喷雾。判断空背景误检时必须看门控前的原始模型指标，不能只看被清空后的结果。

当前物理约束仅为视窗、喷嘴关联及无观测降级。时序状态网络、阶段切换、压力速度模型和透明度物理反演尚未实现。40bar仍为工况记录，不能据此声称已经使用柴油喷速约束。真实边界精度需后续标注评估；合成结果和训练损失不替代真实实验结论。
