# V3 背景参考深度学习开发报告

日期：2026-10-30。V2.0.1为传统算法基线；V3为可运行研发试验版，尚无真实边界准确率结论。

## 第一轮：3.0.0-alpha1

已实现原始空背景保留、视窗外有限光度校正、四通道背景条件轻量U-Net、两次共享细化、喷雾/边缘/不可见性辅助输出，以及视窗、喷嘴关联和无观测降级。模型为自编结构，不是BackgroundMattingV2或BSUV-Net的复现。

增加数据清单与哈希、可控增亮/变暗合成监督、训练与最佳权重保存、独立合成种子测试、真实整段推理、PNG/CSV/对照图导出。桌面工具可切换V2/V3并选择权重，另有本地三类笔刷标注窗口、真实标注微调与评分入口。未知像素不按背景监督或评分。

### 环境与训练

- 工作区独立虚拟环境，复用既有图像依赖；未升级系统Python环境。
- Python 3.13，PyTorch 2.11.0+cu128，RTX 3060 Laptop 6GB；官方wheel SHA256核实通过，GPU实际运算通过。
- 491606参数，训练尺寸320、batch 4、1000步，约252秒，峰值已分配显存886MiB。
- 第1—3帧为空背景参考与合成训练池，第4、5帧留作空背景检查；真实喷雾图像未用于监督训练。人工标注0帧。
- 最佳合成验证IoU约0.900，对应第900步；最后一步并非最佳，推理实际使用best.pt。

### 真实效果自评

第6帧短喷束基本保住，空背景没有明显误检。第20帧模型开始跟踪各喷束，但原始概率将部分窗框亮度变化认作前景；几何筛选后这些区域转为未知提示，不能称为网络已经学会去除窗框。

末帧左右白斑处依然内缩，中央出现较大的不合理分割缺口。与V2相比没有足够证据说明真实边界已经改善，不能用合成IoU上升证明用户核心问题已解决。

第一轮作为可复现基线保存。下一轮针对白斑遮断、窗框光照扰动与晚期合并云团增加合成训练覆盖，保持原始背景和未知输出；是否改善需重新运行和复核。

## 第二轮：3.0.0-alpha2

在第一轮最佳权重上热启动600步，学习率0.0003，约139秒。新增白斑主动遮断、窗框光照扰动、晚期合并云团及低对比前景加权；最佳权重采用合成验证IoU加0.1倍低对比召回选取，本轮选中第400步。没有恢复优化器，不称为精确断点续训。

推理新增512像素细尺度和320像素上下文概率融合，大分歧转为未知。亮背景上缺少变化证据的高分预测也转为未知，避免网络按形状补出的区域被当作确定观测。CLI切换新输入时默认清除旧标定；显式`--reuse-geometry`才复用。保存软件版本及权重版本，兼容第一轮权重。

### 同一合成分布对照

普通测试使用新种子912731，困难测试使用新种子912732。A、B在各自表行使用完全相同的背景和目标样本；均不是真实实验标签。困难测试另含遮断、窗框扰动和合并云团，不能与普通测试的数值直接混比。

### 真实序列与桌面运行

完成A、B的同设置双尺度70帧推理，并通过桌面入口再运行B模型70帧。最终桌面运行约19秒，含读取与导出。第4、5帧与精确背景反事实的门控前模型误检比例仍均为0；第6帧强变化保留1137/1138（99.91%，不是准确率）。70张原图重新核对SHA256，与训练前清单全部一致。

末帧中央大缺口及左右白斑处内缩在视觉上有所收敛，可能来自更强的形状先验，尚不能证明恢复了真实边界。第20帧白斑附近出现提前向外扩张风险；最终图将缺乏观测支持的白斑区明确涂为紫色未知。贴近视窗的边界还可能受视野截断，不能直接作为喷雾真实终点。

因此alpha2仅作为新增试验候选，与alpha1和V2并存；不以整幅轮廓更连续替代真实正确性。当前尚未做独立控制预算的迭代模块消融，也没有真实人工边界测试。

最终源码、权重结构、多尺度形状恢复、弱信号监督、未知评分、训练/保存/推理/批处理流程共14项回归检查通过。GUI参数切换、标注窗口及真实70帧桌面调度另行复核。验证摘要见`validation/v3_alpha2_*.json`和`validation/v3_source_integrity.json`。

下一阶段应先复核第20、54、70帧白斑区域的确定前景、确定背景和未知带，加入真实留出标签；再评估阶段适用的到达时间及前沿增长软约束，重点抑制中期提前扩张。不能通过继续提高形状补全强度掩盖不可辨识区域。

## 当前实现边界

物理部分仍限于标定视窗、喷嘴关联及无观测降级；时序状态网络、阶段切换、定量喷速约束和真实透明度反演尚未实现。40bar为环境背压记录，不单独决定喷速。

未知提示未校准，不能保证覆盖所有错误。`signal_on_black`是模型区域内的观测变化显示，不是恢复的真实无背景喷雾。模型区域与V2外包络定义不同，不能直接比较二者面积当作物理量。

原图、环境、私有配置、大权重及本机处理图不进入Git；源码、说明及去路径的验证摘要保存到专用分支。正式精度与泛化仍需真实复核标签及其他完整实验序列。
