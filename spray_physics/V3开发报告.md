# V3 背景参考深度学习开发报告

日期：2026-10-30。V2.0.1为传统算法基线；V3为可运行研发试验版，尚无真实边界准确率结论。

## 第一轮：3.0.0-alpha1

已实现原始空背景保留、视窗外有限光度校正、四通道背景条件轻量U-Net、两次共享细化、喷雾/边缘/不可见性辅助输出，以及视窗、喷嘴关联和无观测降级。模型为自编结构，不是BackgroundMattingV2或BSUV-Net的复现。

增加数据清单与哈希、可控增亮/变暗合成监督、训练与最佳权重保存、独立合成种子测试、真实整段推理、PNG/CSV/对照图导出。桌面工具可切换V2/V3并选择权重，另有本地三类笔刷标注窗口、真实标注微调与评分入口。未知像素不按背景监督或评分。

### 环境与训练

- 工作区独立虚拟环境，复用既有图像依赖；未升级系统Python环境。
- Python 3.13，PyTorch 2.11.0+cu128，RTX 3060 Laptop 6GB；官方wheel SHA256核实通过，GPU实际运算通过。
- 491606参数，训练尺寸320、batch 4、1000步，约252秒，峰值已分配显存886MiB。
- 第1—3帧为空背景参考与合成训练池，第4、5帧留作空背景检查；真实喷雾图像未用于监督训练。人工标注0帧。
- 最佳合成验证IoU约0.900，对应第900步；最后一步并非最佳，推理实际使用best.pt。

### 真实效果自评

第6帧短喷束基本保住，空背景没有明显误检。第20帧模型开始跟踪各喷束，但原始概率将部分窗框亮度变化认作前景；几何筛选后这些区域转为未知提示，不能称为网络已经学会去除窗框。

末帧左右白斑处依然内缩，中央出现较大的不合理分割缺口。与V2相比没有足够证据说明真实边界已经改善，不能用合成IoU上升证明用户核心问题已解决。

第一轮作为可复现基线保存。下一轮针对白斑遮断、窗框光照扰动与晚期合并云团增加合成训练覆盖，保持原始背景和未知输出；是否改善需重新运行和复核。

## 当前实现边界

物理部分仍限于标定视窗、喷嘴关联及无观测降级；时序状态网络、阶段切换、定量喷速约束和真实透明度反演尚未实现。40bar为环境背压记录，不单独决定喷速。

未知提示未校准，不能保证覆盖所有错误。`signal_on_black`是模型区域内的观测变化显示，不是恢复的真实无背景喷雾。模型区域与V2外包络定义不同，不能直接比较二者面积当作物理量。

原图、环境、私有配置、大权重及本机处理图不进入Git；源码、说明及去路径的验证摘要保存到专用分支。正式精度与泛化仍需真实复核标签及其他完整实验序列。
