# 喷雾项目整体复审与新路线

日期：2026-11-02。状态：旧恢复路线未通过用户验收；新路线为探索试验，尚未形成可测量的最终工具。本报告不将候选掩膜、工程测试或合成配对误差当作真实识别精度。

## 1. 本轮决定

停止沿V5/V6/V6.1继续叠加“去白后补内圈”的修补。保留这些版本和权重，以便复查。撤下README的当前推荐，桌面工具不再因为发现灰底权重而自动选中该模式；旧模式仍能手动复现。

新路线改为：**原始序列与空背景 → 多种观测特征 → 直接喷雾分割、边界及未知区域 → 物理软约束 → 独立显示输出。** 原始图始终保留，均匀灰底不再是识别的唯一输入。用户的去白目标仍然存在，但在没有验证喷雾识别前，不先用一个欠定恢复器改写输入。

本轮已完成原始70帧的四种方法对照和可复现研究入口，没有训练所谓V7成功模型。方向结构分支值得继续用作特征，但仍漏掉白斑重合及低角向对比区域，不能直接作为完整喷雾掩膜。

## 2. 新确认的光路与原始观测

用户确认灯光主要在相机同侧或侧面。仅凭这些信息，不能将该组图当作背光透射图直接使用Beer–Lambert定律，也不能认定它是特定波长、单次散射的定量Mie成像。当前更适合先用不要求精确光学分层的识别方法。

工况继续记录为：柴油、空气、环境40 bar、喷油端名义140 MPa、喷孔0.23 mm、观测圆60 mm；空气25 ℃是授权建模假设。压力基准、燃料物性、实际喷射率及光路几何仍不完整。观测圆不是物理壁面。70张导出图与原录像5522帧不是相互矛盾的记录，但连续帧时间映射仍未独立核验。

原始图审计以第1—3帧中位图为背景，将背景灰度大于0.65×255的视窗内像素作为“高亮区域代理”，不是人工精确白斑标注。其面积为26651像素：

| 原始审计项 | 结果 | 能说明什么 |
|---|---:|---|
| 第1帧高亮代理中灰度≥250的比例 | 0.0113% | 白斑并非大面积饱和，不能笼统说信号全丢失 |
| 第70帧该区域灰度≥250的比例 | 0% | 此帧大面积纯白裁切不是主要证据 |
| 第13帧相对背景变化超过6灰度的比例 | 25.55% | 重合区域仍有可用变化 |
| 第50帧同一指标 | 44.90% | 后期也不应把整个白斑区预先删掉 |
| 第70帧同一指标 | 50.42% | 变化存在，但变化本身不等于喷雾类别 |

上述统计使用视窗外的有限增益、偏置校正，没有在喷雾内部拟合曝光。它不证明能逐像素唯一分离反光和散射；也不排除约一帧曝光带来的运动模糊。两类问题应分别诊断。

## 3. 旧路线为何没有解决问题

| 环节 | 具体问题 | 处理决定 |
|---|---|---|
| 光学分层 | 单灰度像素在`I≈T·B+S`中同时有未知T、S，许多组合都能解释I；构造灰底不是配对真值 | 不再用低重构残差证明恢复正确 |
| 合成与反事实训练 | 几何合成和真实纹理再打光只提供代理监督，不能验证原始光斑重合区域 | 保留为预训练或压力测试，不作为真实准确率 |
| 时序使用 | V6前后帧替换成当前帧时，代理误差几乎不变 | 以后必须做明确的时序消融，检查是否真的用到序列 |
| V6.1内圈保护 | 少扣背景能让图像变亮，但没有证明恢复了真实喷雾 | 不继续以亮度增加冒充恢复率 |
| 边界输入 | 先损伤喷雾，再从损伤图捕边界，会把恢复偏差传给测量 | 从原始观测直接识别，保留审计叠加图 |
| 评价 | 没有真实人工标签；工程合同测试、合成误差不等于真实边界精度 | 报告中分开记录，未知位置不编造真值 |
| 物理前沿 | 只建模贯穿距，不能唯一决定完整二维轮廓，更不能恢复纹理 | 当前关闭硬裁切、硬补全 |

既有物理试验在55个处理图参考点上的平均误差1.576 mm，约18像素；最大误差约5.052 mm，约58像素，区间覆盖约49.1%。而且参考点来自V6处理图、最困难白斑方向样本稀少，不是原始真值。这种水平不支持用物理曲线删掉真实图像边界。详见历史[物理试验报告](空气25C物理约束试验报告.md)。

## 4. 本轮实际运行的方法和结果

入口：`raw_sequence_audit.py`。前1—3帧只用于背景及噪声标定，第4—5帧留作空背景检查，随后处理全部70帧。三帧窗口只用当前和过去两帧。视窗ROI为367478像素，仅排除喷孔附近约20.5像素半径，不再排掉35—150像素的内圈。

- A：固定背景亮度绝对差分，阈值6灰度，滞后阈值连接弱证据。
- B：三帧时间总体标准差，再做5×5空间样本标准差，阈值约1.879灰度。数学思路参考ECN公开方法，独立实现；未移植其单喷束最大连通域、液芯补画和填洞。
- C：A、B归一化分数取最大后连接，检验简单融合是否足够。
- D：对有符号背景差分按喷孔坐标展开极坐标，在每一半径沿角度去掉20°高斯平滑趋势，保留正向喷束局部对比，强阈值8灰度。结构分支不要求每块远端喷雾必须经高对比像素连回喷孔，只滤小于64像素的孤岛；这避免低对比根部断开时删掉整束。

阈值按空背景噪声及明确的灰度下限给定。此轮已经观察和调整过实现，属于探索性对照，不称盲测。所有方法在第4、5帧的最终候选误检均为0像素，但只有两张同场景空帧，不能推广为误检率为零。

| 方法 | 第13帧候选像素 | 第50帧候选像素 | 第70帧候选像素 | 本轮判断 |
|---|---:|---:|---:|---|
| A 亮度差分 | 277939 | 351602 | 352439 | 广域亮度变化连成大块，不能当喷束外缘 |
| B 时序纹理 | 148021 | 1870 | 182 | 后期几乎失效，不能单独承担识别 |
| C 简单融合 | 304981 | 353913 | 354773 | 继承差分过宽的问题，淘汰为最终方案 |
| D 角向结构 | 65096 | 156032 | 150577 | 喷束结构更明确，保留为辅助特征 |

D在第13、50、70帧的阈值±20%扰动IoU约为0.813、0.905、0.889。**这是两种阈值结果之间的稳定性，不是与人工真值比较的IoU。** A虽然更稳定，却会圈住接近整个视窗，因此稳定性本身也不能证明准确。

D也有明确失败：第70帧内圈代理区域仅约30.2%进入结构候选，强白背景代理区几乎没有被纳入。这里既有低对比，也有角向平滑主动去掉的宽角度成分，不能解释为剩余位置没有喷雾。受控测试也证明，轴对称浓雾可以被该特征消掉。因此D的中间图明确叫“有符号结构特征+100”，不是去白恢复图；D掩膜不得用于删除原图像素。

完整数值见[原始序列试验摘要](原始序列试验摘要.json)。本地保存70帧各候选PNG、原图叠加、逐帧CSV、输入哈希、代表帧对照和动画；原图及ECN下载源码不进入Git仓库。

## 5. 新方案：有真实监督的原始序列分割

目标先明确为识别“可辨认的喷雾投影区域”，区分可见喷束与弥散雾；白斑重合、强模糊及观测不足位置允许标未知，不能凭暗或亮单一阈值定义喷雾。

**输入与网络。** 原始当前及过去图像、起喷前背景为主输入。A的有符号差分、B的动态纹理、D的有符号方向结构只作为附加通道；保留笛卡尔坐标分支识别内圈宽雾，极坐标分支提供喷束方向和外沿特征。先用可控的小型U-Net类基线检验真实标签是否带来收益，再决定是否增加时序卷积或ConvGRU；不在70帧零标签上直接追求更大模型。

**输出与监督。** 输出喷雾概率、边界概率及未知标记。以少量关键帧的真实人工核查掩膜为监督，背景/喷雾/未知三类分别记录；未知像素不强行加入二分类损失。先选起喷、中段、后期、白斑交叠和内圈样例，建立固定核查集。算法自动候选只能加速标注，不能未经核查就变成人工真值。此前合成或反事实样本可作预训练，最终必须接受真实标签约束。

**物理位置。** 贯穿距规律只约束有观测支持的外沿轨迹；参数、时刻及投影均需校准。误差区间未校准前，物理损失权重为0；通过核查后再逐步启用软惩罚。不能用单调增长强迫后期区域保持扩张，不能假设所有喷束完全对称，也不能将视窗截断当成喷雾尖端。物理约束不能替代光学观测或真实监督。

**时序验证。** 比较单帧、真实历史帧、历史帧重复当前帧、历史帧乱序四种输入；如果真实时序没有额外收益，就不保留复杂时序模块。不能仅因网络接收了多帧就声称利用了发展规律。

**显示与去白。** 识别结果先叠加在原图上核查。后续可将有把握的背景替换为均匀灰底，喷雾及未知区另行处理；未知区不得为了白斑完全消失而直接擦除。语义分割渲染不是光学恢复真值。若要求重合区白斑全部消失且真实喷雾灰度完全保留，单通道现有数据尚不能保证，需增加有辨识力的观测或可信配对监督。

## 6. 验收和停止条件

1. 先建立并冻结真实核查标签；当前全部70帧都已用于探索，不能再把其中后段包装成完全未见的最终盲测。
2. 分别报告清晰喷束、白斑交叠、后期内圈及空背景的结果。采用可辨认区域IoU、不同像素容差下的边界F分数、物理标定后的边界距离；同时公开未知比例及覆盖率，防止把难点全部拒判来提高分数。
3. 尤其检查内圈误删与白斑残留。没有配对无白斑图时，不报告“恢复灰度真值误差”。
4. 后续其他完整序列按整段实验留出，禁止相邻帧随机混分训练测试。新数据未到前，可完成特征检查和标注准备，不能声称跨工况泛化已经实现。
5. 若真实监督分割仍无法辨别重合区，再考虑受控光路实验，例如改变照明方向或偏振、调整曝光并作对照；重复喷射不是同一时刻的像素配对真值。先证实新观测确实增加对比，再谈恢复网络。

## 7. 复现与工程检查

在工具目录使用当前已核验标定配置运行：

```powershell
python raw_sequence_audit.py --config config.json --output "<原图目录之外的独立结果目录>" --reference-frames 3 --empty-frames 5
python -m unittest test_raw_sequence_audit -v
```

新序列可用`config.example.json`配合`--input "<新序列目录>"`，工具重新估计几何，输出后仍须核对；不要默认每段序列前5帧都无喷雾。新输入不继承本案例已确认的照明事实。

8项工程测试通过，包括固定白斑不产生运动特征、静态喷雾会被运动法漏掉、轴对称雾会被角向对比漏掉、远端喷束不能因根部低对比而删除、无强制填洞/增长，以及修改未来帧不影响较早输出、原输入字节保持不变。这些是实现行为验证，不是实际边界精度证明。

## 8. 一手资料及适用边界

- [ECN喷射贯穿距诊断](https://ecn.sandia.gov/diesel-spray-combustion/experimental-diagnostics/jet-penetration/)与[官方处理代码说明](https://ecn.sandia.gov/schlieren-code/)：时序导数纹理用于喷雾边界。本轮已核查其三帧时间标准差再做空间标准差的实现，但其主要对象为施里伦等诊断，不直接证明适合当前同侧照明图。
- [Payri等，Fuel 188 (2017)，喷孔几何与喷雾形成研究，作者公开稿](https://riunet.upv.es/bitstream/10251/104019/2/TobComb_evaporativeUPV.pdf)：时序导数方法对变化很小的浓密区域存在限制，可与强度敏感方法结合。本轮对照进一步说明，对本数据简单融合仍然不足。

角向去趋势是本项目探索的结构特征，不冒称上述论文的完整算法或已经证明的去反射方法。
