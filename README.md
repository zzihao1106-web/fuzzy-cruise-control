# 基于模糊控制的汽车定速巡航

浙江大学《车辆动力学控制》课程作业。用 Simulink 搭一个模糊控制器，让汽车自动保持驾驶员设定的车速，上坡也不掉速。

## 被控对象

整车纵向动力学，只有一条力平衡方程：

```
m · dv/dt = F_d − F_r
F_r = mgf + ½ρCdA·v² + mg·grade
```

阻力三项分别是滚动阻力、空气阻力、坡道阻力。整车参数按 1.5 t 家用轿车取值，最大驱动力 3000 N。

## 控制器

模糊控制器，2 个输入、1 个输出、5 档语言变量、25 条规则：

| | 含义 |
|---|---|
| 输入 `e` | 车速误差 = 设定车速 − 实际车速 |
| 输入 `ec` | 误差变化率 de/dt |
| 输出 `Δα` | 油门开度的增量 |

输出是**增量式**的（`α ← α + Ku·Δα`），所以有积分作用，稳态误差能消掉。控制器按 0.1 s 采样周期离散工作。

## 仿真结果

跑两次，手动改「坡度」常数的值：

| 工况 | 车速 | 油门开度 |
|---|---|---|
| 平路（`grade = 0`） | 稳在 80 km/h | 14.45% |
| 5% 上坡（`grade = 0.05`） | 最低掉到 79.1，2 秒后回到 80 | 自动加到 38.98% |

上坡时多出的 736 N 正好是坡道多要的驱动力，车速几乎不变。

Simulink 模型与手写 MATLAB 参考解交叉校核，最大车速偏差小于 0.004 m/s。

## 文件说明

| 文件 | 作用 |
|---|---|
| `CruiseFuzzy.slx` | Simulink 模型（顶层：2 个常数 + 2 个子系统 + 示波器） |
| `cc_params.m` | 全部参数（车重、阻力系数、控制器参数、设定车速、坡度） |
| `cc_fis.m` | 模糊推理系统（5 档语言变量 + 25 条规则） |
| `cc_sim.m` | 纯 MATLAB 参考仿真 |
| `cc_build.m` | 用脚本自动生成 Simulink 模型 |
| `cc_run.m` | 跑两次仿真、校核、出图 |
| `cc_init.m` | 模型打开时自动加载参数 |
| `run_all.m` | 一键复现全部结果 |
| `fis/cruise_fuzzy.fis` | 模糊推理系统文件 |
| `results/` | 仿真结果图 |
| `汇报PPT_模糊控制定速巡航.pptx` | 汇报用 PPT（8 页） |

## 怎么跑

1. MATLAB 里把本文件夹设为当前文件夹
2. 一键复现：运行 `run_all.m`
3. 或者手动：打开 `CruiseFuzzy.slx`，双击 `grade` 方块，值填 `0`（平路）或 `p.grade`（5% 上坡），点运行

## 环境要求

- MATLAB R2024a
- Simulink
- Fuzzy Logic Toolbox
